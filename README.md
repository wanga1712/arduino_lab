# Arduino Lab

Виртуальная учебная лаборатория для знакомства детей 10+ лет с Arduino и базовой электроникой.

## Текущий статус

Проект находится на этапе планирования WIP-001. Исходного кода приложения пока нет. Первый вертикальный срез должен провести ученика через урок «Мигающий светодиод»: от пустой схемы до проверки соединений, запуска ограниченного Blink-сценария, серверного сохранения прогресса и скачивания настоящего `.ino`-скетча.

На момент первичного аудита 27 октября 2026 года:

- создан Git-репозиторий, рабочая ветка `feature/wip-001-arduino-lab-mvp` и GitHub remote;
- Node.js и npm не найдены в `PATH`;
- создан архитектурный каркас web/API/shared/PostgreSQL/deploy, но исходная реализация ещё отсутствует;
- зависимости, сборка и тесты отсутствуют;
- доступны техническое задание, правила и план поэтапной реализации.

## Границы WIP-001

В первой версии будет поддержан только урок Blink и документированный поднабор Arduino C++. Это не полноценный компилятор, AVR-эмулятор или SPICE-симулятор. Аккаунты, платежи, авторизация Stepik и работа с физической Arduino в WIP-001 не входят.

Целевая архитектура включает React-клиент, Node.js API и PostgreSQL. База хранит анонимные лабораторные сессии и прогресс, а локальное состояние браузера служит кэшем и защитой от временной недоступности API. Весь стек должен быть развёрнут через HTTPS на Ubuntu-сервере №13; реквизиты доступа и production-секреты в репозитории не хранятся.

## Порядок разработки

Работа выполняется по одному этапу из плана. Каждый этап проходит отдельное ревью до начала следующего. Этот README обновляет ревьюер только после фактической проверки принятой функциональности, поэтому он не описывает ещё не реализованные возможности как готовые.

Кодер обязан сначала искать существующий модуль с нужной функцией. Рукописные исходные и тестовые модули ограничены 150 строками; дублирование обязанностей и циклические зависимости запрещены. README, лицензирование, `.gitignore`, коммиты и push ведёт ревьюер проекта.
