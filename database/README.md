# Database

Последовательные SQL-миграции PostgreSQL. Уже применённые миграции не редактируются; любое изменение схемы оформляется новым файлом.

PostgreSQL является источником опубликованной структуры курсов, версий уроков, каталога компонентов/датчиков, их пинов и параметров правил. Электрические правила реализуются в `packages/shared`, а собранная схема ученика сохраняется версионированным JSONB-снимком.

Дампы, резервные копии и production-секреты в Git не хранятся.
