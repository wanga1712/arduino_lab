# WIP-001-00 — воспроизводимый каркас проекта

## Цель

Создать минимальный запускаемый npm-workspace для Arduino Lab: React-клиент, Fastify API, общий TypeScript-пакет и автоматические архитектурные проверки. Этот WIP не реализует лабораторию, электрическую модель или PostgreSQL.

## Обязательный аудит до изменений

1. Прочитать `AGENTS.md`, `README.md`, `IMPLEMENTATION_PLAN.md` и `docs/ARCHITECTURE.md` полностью.
2. Проверить управляющие файлы `WIP`, `WIP.md`, `docs/WIP`, `docs/WIP.md`.
3. Выполнить `git status --short --branch` и не менять ветку или remote.
4. Через `rg --files` проверить существующую структуру.
5. Через `rg` найти существующие package-конфигурации, точки запуска, health handlers, URL parsing и архитектурные scripts до создания новых.
6. Зафиксировать доступные версии Node.js и npm. Если их нет, остановить реализацию и честно сообщить блокер; системная установка среды не входит в этот WIP.

## Разрешённый объём

### Workspace

- Настроить корневой npm-workspace для `apps/web`, `apps/api`, `packages/shared`.
- Добавить один корневой `package-lock.json`; вложенные lock-файлы запрещены.
- Добавить Windows-совместимые scripts: `dev`, `build`, `typecheck`, `test`, `check:architecture`.
- Использовать только локальные зависимости проекта, без CDN и глобальных npm-пакетов.
- Включить строгий TypeScript для всех workspace-пакетов.

### Web

- Создать Vite + React + TypeScript приложение без демонстрационных компонентов и ассетов.
- Поддержать URL `/lab?lesson=blink` без подключения библиотеки маршрутизации.
- Для `lesson=blink` показать только оболочку с названием Arduino Lab, названием урока и честным статусом «Лаборатория готовится».
- Для отсутствующего или неизвестного `lesson` показать понятную русскую ошибку.
- Не рисовать Arduino, breadboard, компоненты или фиктивные действия.

### API

- Создать минимальный Fastify-сервис с отдельной фабрикой приложения и отдельной точкой запуска.
- `GET /api/health/live` возвращает HTTP 200 и стабильный JSON-код живого процесса.
- `GET /api/health/ready` до подключения PostgreSQL возвращает HTTP 503 и стабильный код `DATABASE_NOT_CONFIGURED`.
- Не подключать PostgreSQL, миграции, repository или фиктивное in-memory-хранилище.
- При завершении процесса корректно закрывать Fastify.

### Shared

- Создать компилируемый пакет с минимальным публичным `index.ts`.
- Не добавлять заранее доменные типы Circuit, Lesson, API DTO или BlinkEngine: они появятся в соответствующих WIP после поиска и согласования.

### Архитектурные проверки

- `npm run check:architecture` должен выполняться кроссплатформенно через локальные Node-инструменты.
- Проверка отклоняет рукописные `.ts`, `.tsx`, `.js`, `.jsx`, `.css`, `.scss`, `.sql` длиннее 150 физических строк.
- Проверка запрещает импорты `web → api`, `api → web`, `shared → apps` и выявляет циклические зависимости.
- Проверка ищет технические копипаст-дубли, исключая lock, generated, build, coverage и документацию.
- Конфигурация проверки не должна дублировать список границ в нескольких scripts: один источник правил, несколько потребителей при необходимости.

## Обязательные целевые тесты

- Web smoke-test для поддерживаемого `lesson=blink`.
- Web test для неизвестного урока.
- API test через Fastify injection: `live` возвращает 200.
- API test через Fastify injection: `ready` возвращает 503 и `DATABASE_NOT_CONFIGURED`.
- Проверка architecture guard на заведомо длинном временном fixture и запрещённом импорте без сохранения этих нарушений в рабочем дереве.

- Реализовывать circuit/netlist, SVG-платы, компоненты, редактор кода, localStorage, PostgreSQL или синхронизацию.

- Выполнять commit, push, менять Git remote или переписывать историю.
- Обходить лимит 150 строк минифицированием, несколькими выражениями в одной строке или бессодержательным дроблением.

## Критерии приёмки

- `npm install` из корня создаёт весь workspace.
- `npm run build`, `npm run typecheck`, `npm run test`, `npm run check:architecture` завершаются успешно на Windows.
- `npm run dev` запускает web и API одной корневой командой.
- Web открывает корректную оболочку для Blink и ошибку для неизвестного урока.
- Health endpoints возвращают заявленные HTTP-статусы и JSON-коды.
- Нет рукописных модулей длиннее 150 строк, циклов, запрещённых импортов и выявленных копипаст-дублей.
- Нет функциональности из следующих WIP и нет ложных заявлений о готовности PostgreSQL.
